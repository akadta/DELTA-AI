## ✨ Features

- 💬 **Real-time AI chat** with streaming responses
- ⚡ **Ultra-low latency** powered by Groq inference
- 🧠 **Context-aware conversations** that remember chat history
- 📝 **Markdown & code highlighting** in replies
- 🌗 **Dark / Light theme** support
- 🗂️ **Multiple chat sessions**
- 📱 **Fully responsive** on desktop and mobile
- 🔐 **Secure API handling**: your Groq key stays on the server

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/akadta/DELTA-AI.git
cd DELTA-AI
```

### 2️⃣ Setup the backend

```bash
cd server
npm install
```

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key_here
PORT=5000
```

Start the server:

```bash
npm run dev
```

### 3️⃣ Setup the frontend

```bash
cd client
npm install
npm run dev
```

### 4️⃣ Open the app

```
http://localhost:5173
```

## 🔑 Get Your Groq API Key

1. Visit [console.groq.com](https://console.groq.com)
2. Sign up / log in
3. Create an API key
4. Paste it into your `.env` file
